# BOM 表结构详解

## 数据文件

- **路径**：`/Users/taojing/Documents/OpenClaw_Docs/Bom/`
- **命名规则**：`YYYY年M月bom表.xlsx`
- **结构**：三表结构一致（不同月份表结构相同，仅数据不同）

## 维度规模（示例：2026年1月表）

- **产品数**：N 个（完工产品）
- **物料种类**：M 种
- **Sheet 1**：小包装（70g/盒为基础规格）
- **Sheet 2**：大包装（500g×18盒/箱）
- **金额单位**：元（人民币），默认

## 列结构（表头区）

| 行    | 内容                                                             |
| ----- | ---------------------------------------------------------------- |
| Row 1 | 代码（产品编码，如 FC0000018-1）                                 |
| Row 2 | 品名（产品名称，如 芥末章鱼）                                    |
| Row 3 | 规格（包装规格，如 70g/盒）                                      |
| Row 4 | 入库重量（完工产品维度，单位 kg）                                |
| Row 5 | 物料耗用表头：物料编码 / 耗用材料 / 数量 / 金额（每个产品占2列） |

## 交叉表结构

- **每行** = 物料
- **每2列** = 一个产品的（数量 + 金额）
- Row 1-4：产品维度信息（代码/品名/规格/入库重量）
- Row 5：物料耗用表头
- Row 6+：具体物料消耗明细

## SKU 基础信息

同一列中代码+品名+规格构成一个 SKU。

示例：`FC0000018-1 / 芥末章鱼 / 70g/盒`

## 物料编码前缀分类（正式分类）

| 前缀 | 类别               |
| ---- | ------------------ |
| FS00 | 辅材类             |
| YS00 | 原料类（海鲜为主） |
| BS00 | 包材类             |
| ZJ00 | 佐料类             |
| FD00 | 辅料类             |
| YHTL | 鱼糜类             |
| FY00 | 辅助材料           |

## 小包装 sheet 物料命名规则（首字母分类）

| 首字母 | 类别       |
| ------ | ---------- |
| Y      | 原料       |
| F 或 Z | 辅料       |
| B      | 小包装包材 |

## 规格与包装单位

| Sheet  | 规格表示               | 最小包装单位 |
| ------ | ---------------------- | ------------ |
| 小包装 | 500g/盒、500g/袋 等    | 盒 或 袋     |
| 大包装 | 500g×18盒、1kg×12袋 等 | 箱           |

## 单位说明

| 维度           | 单位       |
| -------------- | ---------- |
| 入库重量       | 公斤（kg） |
| 原料数量       | 公斤（kg） |
| 辅料数量       | 公斤（kg） |
| 小包装包材数量 | 个         |
| 大包装包材数量 | 个         |

> 注：同一耗用材料因供应商不同，物料编码可能不同（如：YS0000004 章鱼段）

## 核心理解

1. **交叉表结构**：每行=物料，每2列=一个产品的（数量 + 金额）
2. **Row 1-4**：产品维度信息（代码/品名/规格/入库重量）
3. **Row 5**：物料耗用表头
4. **Row 6+**：具体物料消耗明细
5. **入库重量**：按完工产品维度统计，非物料汇总
6. **SKU 基础信息**：同一列中代码+品名+规格构成一个 SKU（如：FC0000018-1 / 芥末章鱼 / 70g/盒）
7. **物料信息**：同一行中物料编码+耗用材料构成生产该 SKU 所需的某种物料

## 成本计算逻辑（铁则）

- **不宜将小包装+大包装工序成本直接相加**（两工序完工入库重量未必一致，大包装可能并入上月未装箱产品）
- 小包装 1kg 成本 = 小包装工序成本 ÷ 小包装工序入库重量
- 大包装 1kg 成本 = 大包装工序成本 ÷ 大包装工序入库重量
- 总 1kg 成本 = 小包装 1kg 成本 + 大包装 1kg 成本
- 某 SKU 单品成本 = 总 1kg 成本 × 规格（kg）

## 工序与产品代码规则

| 工序   | 产品代码格式                 | 示例        |
| ------ | ---------------------------- | ----------- |
| 小包装 | 代码 + "-1"                  | YQ0000004-1 |
| 大包装 | 公司真正的成品代码（无后缀） | YQ0000004   |

**注意**：询问 YQ0000004 产品成本时，默认指两道工序（包材+大包装）总成本，而非单指大包装工序。

## 大包装包材

- 以字母 B 开头
- 数量单位为个
- **实例（YQ00109XS，2026年1月）**：当月完工入库 500 kg 成品，耗用 BS0000063 味极致-空白盒 × 500 个，对应成本金额 ¥300.81

## 出成率（只适用于小包装工序原料）

- **定义**：小包装完工入库重量 ÷ 某原料耗用数量
- **适用范围**：仅原料（Y开头），不适用于辅料（F/Z开头）和包材（B开头）
- **分类口径**：按「耗用材料」汇总（区分物料品种），而非按「物料编码」汇总（物料编码同时区分供应商，耗用材料仅区分品种）
- **多物料处理**：若某产品原料涉及多种耗用材料，需分别按耗用材料计算各自的出成率
- **取数范围**：仅限小包装工序，不涉及大包装

## 计算规则（铁则）

1. **月份一致性**：所有小包装和大包装数据必须取自同一月份（绝大多数情况下两工序数据同月份）
2. **月份确认**：每次计算前必须先打印月份，确认后再进行下一步
3. **禁止跨月复用**：不得复用跨月份的中间值
4. **打印产品基础信息**：计算前必须打印产品代码、品名、规格、入库重量，禁止依赖缓存描述
